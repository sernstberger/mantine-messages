# Security policy

## Supported versions

Security fixes are released for the latest minor version. Older versions do not receive
security updates, upgrade to the latest version to receive fixes.

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/sernstberger/mantine-messages/security/advisories/new).

Include the affected version, a minimal reproduction, and the impact you have identified.
Once a fix is released, you will be credited in the advisory unless you prefer to stay anonymous.
